# PRDs do projeto Minerva

**Autor:** Cristóvão Augusto

## Para o futuro agente

Esta pasta contém o espelho versionado dos Product Requirements Documents (PRDs) do projeto Minerva. Cada PRD registra escopo, motivo e critérios de aceite de uma entrega; a cópia canônica vive na base oficial do Obsidian.

PRDs são criados just-in-time para uma task pela skill [`../skills/gerar-prd.md`](../skills/gerar-prd.md), respeitando o fluxo e os limites definidos em [`../rules.md`](../rules.md). O antigo diretório `docs/prd/` foi consolidado aqui; o índice abaixo lista somente os PRDs que existem neste repositório.
