# Tokens visuais

Os valores abaixo são contrato. O uso de cor não pode ser o único indicador de estado.

## Cor

| Token | HEX | Intenção |
|---|---|---|
| `color-primary` | `#1B6CA8` | ação, seleção e identidade |
| `color-primary-hover` | `#155A8A` | ação em hover |
| `color-primary-light` | `#E3F0F9` | superfície selecionada discreta |
| `color-primary-deep` | `#0B2E4F` | texto/contraste de identidade |
| `color-background` | `#FAFAF9` | fundo geral |
| `color-surface` | `#FFFFFF` | superfície e drawer |
| `color-border` | `#E4E4E1` | divisórias e contornos |
| `color-text-primary` | `#1A1A18` | texto principal |
| `color-text-secondary` | `#6B6B66` | texto secundário |
| `color-success` | `#12805C` | sucesso |
| `color-warning` | `#B2740B` | aviso |
| `color-error` | `#C0362C` | erro |

Os neutros são quentes, bege acinzentado e não cinza puro, para o azul não gelar a tela. Verde e vermelho são dessaturados de propósito: cor saturada em cada linha de tabela vira ruído.

## Espaçamento, raios e elevação

- Escala base: `space-1: 4px`, `space-2: 8px`, `space-3: 16px`, `space-4: 24px`, `space-5: 32px`, `space-6: 48px`.
- Raios: `radius-sm: 4px`, `radius-md: 8px`, `radius-lg: 12px`, `radius-pill: 999px`.
- Elevação: `elevation-0: none`, `elevation-1: 0 1px 2px rgba(26,26,24,.08)`, `elevation-2: 0 4px 12px rgba(26,26,24,.12)`, `elevation-3: 0 12px 32px rgba(26,26,24,.16)`.

## Lacuna

❓ LACUNA: o tema escuro ainda não foi desenhado. Não fazer inversão automática destes tokens; qualquer tema escuro exige desenho e decisão próprios.
