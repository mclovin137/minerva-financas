# Tipografia

Este documento é contrato de tipografia e de legibilidade.

- Display: `Sora 600`; saldo principal em `44px`, título de página em `28px`.
- Corpo e interface: `Public Sans 400/500/600`; base de `16px` e linha `1.55`.
- Dados: `Public Sans`, `font-variant-numeric: tabular-nums`, valores em `15px`.
- Labels: `12px 600`, `letter-spacing: .04em`; caixa alta somente em cabeçalho de tabela.
- Texto secundário: `13px`.
- Nunca usar tamanho abaixo de `12px`.

CONTRATO: toda coluna de número monetário usa `tabular-nums`. Sem isso os dígitos dançam a cada atualização e a comparação visual fica inválida.

❓ LACUNA: carregamento, fallback e hospedagem das fontes não foram desenhados.
